# Alcance inicial

## Entrada de documentos

El laboratorio debe admitir dos mecanismos principales:

1. Subir un archivo.
2. Capturar una fotografía mediante la cámara.

Formatos iniciales previstos:

- PDF
- JPG
- JPEG
- PNG

## OCR

El sistema debe permitir evaluar documentos:

- impresos limpios;
- impresos degradados;
- con bajo contraste;
- con ruido;
- inclinados;
- fotografiados con perspectiva;
- con caracteres ambiguos;
- manuscritos legibles;
- manuscritos irregulares.

## Restricción

No se entrenará un modelo OCR nuevo.

## Integración TEVI

Ninguna implementación experimental se añadirá a MVP-TEVI hasta que
el laboratorio haya superado el benchmark y las pruebas correspondientes.
